# 动漫与漫画排名

可在浏览器中使用的作品排名工具，支持档位排名、十分制评分和对比排名。

网站文件位于 `site/`。目前收录 2100 部动画和 550 部漫画，支持搜索、题材筛选、自定义封面、图片导出及手机/iPad布局。

## 发布

在仓库 Settings → Pages 中，将 Source 设为 GitHub Actions。推送到 main 分支后，内置工作流会发布 `site/` 中的网站。

发布完成后，分享 Pages 页面提供的网址即可。网站访客不需要 GitHub 账号。

## 数据保存

每个人的排名、评分和自定义作品只保存在自己的浏览器中。换设备、换网址或清除网站数据后，原有记录不会自动同步。原站的本地排名不会随源码上传到 GitHub。

作品资料与封面来自 [Bangumi](https://bgm.tv/)。
